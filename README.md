# Описание
### Классификация пород собак на базе EfficientNetV2B0 (Transfer Learning)

Обученная модель решает задачу многоклассовой классификации пород собак по изображениям.

#### Что реализовано в проекте:

• Проект выполнен на TensorFlow/Keras.

• В качестве датасета был выбран архив Stanford Dogs.

• Модель EfficientNetV2B0 с предобученными весами ImageNet.

• Для обучения был выбран двухэтапный fine‑tuning. Сначала обучалась только классификационная голова (7 эпох), затем размораживаются верхние 40 слоёв сети (4 эпохи) с пониженным learning rate.

• Для предобработки и очистки данных была выполнена фильтрация битых JPEG‑файлов по маркеру JFIF.

• Было выполнено автоматическое разбиение датасета на train/val/test.

• Проведена гибкая аугментация для снижения переобучения.

• После обучения была выполнена оценка на тестовом изображении.
